Information stored on your device

Theme preference, saved resources, the selected AI model, a short recent-resource list and a random AI rate-limit identifier use browser local storage. The identifier helps apply a short per-visitor limit; it is not a visitor account or profile. These values do not sync between devices, and clearing site data removes them.

Browser-powered translation

When it is supported, choosing हिन्दी uses the browser's Translator API to translate visible page text in place with a browser-provided, on-device model. The browser may download a language pack, but Pigsfield does not send the page URL or its content to Google Translate. If the API is unavailable, the site only explains how to use the browser's own Translate-page menu; it does not open an external translator. A browser vendor's terms apply if a visitor chooses that browser feature. The English page remains the source version.

YouTube playback

The player is created only after you press Play and uses YouTube's privacy-enhanced domain. YouTube still receives the network information necessary to deliver the player. The site preserves a strict-origin referrer because YouTube requires site identity for embedded playback. If you do not want that connection, use the original link or do not start the player.

AI studio

The text selector offers gpt-oss (Cloudflare Workers AI model @cf/openai/gpt-oss-120b) and gpt-5.4-mini (third-party model openai/gpt-5.4-mini through Cloudflare). Tutor and document prompts are sent to Pigsfield's same-origin /api/ai endpoint. Visitors do not log in, provide a provider API key or download a model. Pigsfield, Cloudflare and the selected model provider receive the request information needed to process a prompt. Rate limits, shared capacity and service availability apply; GPT-5.4 mini also requires Pigsfield's deployment to have Cloudflare Unified Billing and credits enabled.

Image prompts use the named Pollinations image service, so those prompts and the network information needed for the request reach Pollinations. Voice preview and music synthesis are offered only when the browser exposes the necessary capability and their output is made in the browser. Generated images, documents and music files remain downloadable where the browser supports the format. External links to Artificial Analysis, Gemini, ChatGPT, Claude and Z.ai open those providers' own sites and terms. Do not submit personal, confidential, copyrighted or sensitive information to any cloud service. Generated output may be inaccurate, biased or unsuitable and must be reviewed.
