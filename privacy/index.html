Information stored on your device

Theme and language preferences, saved resources, the selected AI model and a random service rate-limit identifier use browser local storage. Pigsfield does not keep a history of the resources you open. The identifier helps apply short per-visitor AI and translation limits; it is not a visitor account or profile. These values do not sync between devices unless you choose to sign in (see Optional sign-in), and clearing site data removes them.

The homepage monthly counter uses a short-lived, first-party cookie that contains only the current India calendar month. It helps avoid counting the same browser repeatedly. The counter stores the monthly total and the date counting began—not visitor identities, raw addresses or profiles. Cookies can be blocked or cleared and one person may use multiple browsers, so the displayed number is explicitly a best-effort browser check-in count rather than an exact count of people.

Optional sign-in

Pigsfield does not require an account and nothing on the site is behind one. Signing in does exactly one thing: it lets the list you saved with the heart button follow you between devices. If you never sign in, that list stays in this browser exactly as before, and no request is ever made to the sign-in service.

Your email address is never stored. When you ask for a sign-in link, the address is used to send that one email and is then discarded. What is kept is a one-way, salted hash of it — enough to recognise you signing in again, and not usable to contact, profile or identify you. Sign-in links work once and expire in 15 minutes. Session identifiers are stored hashed, so a copy of the database could not be used to sign in as anybody.

The only other thing an account holds is the saved list itself: the title, description, link and section of each resource you chose to save. There is no record of what you browsed, searched or opened. Sign out at any time from the saved-list panel, which deletes the session on the server rather than only clearing the cookie; email zeroisinf@gmail.com to have an account and its saved list deleted entirely.

Hindi translation

Choosing हिन्दी translates loaded translatable interface text in place and remembers that language preference on this device. Where the browser supports its Translator API, translation uses a browser-provided on-device model. Otherwise, loaded translatable English interface text—including page copy, accessible labels, titles and placeholders—is sent in limited batches only to Pigsfield's same-origin /api/translate endpoint, which uses Cloudflare-hosted AI4Bharat IndicTrans2. Text typed by the visitor is never included. The request is rate-limited and uses a no-referrer policy. It does not include the page URL, require a visitor account or provider key, or send text to Google Translate. The original English text is retained so EN can restore it instantly. Browser-menu guidance appears only if both translation paths fail; a browser vendor's terms apply if a visitor then chooses that browser feature. The English page remains the source version.

YouTube playback

The player is created only after you press Play and uses YouTube's privacy-enhanced domain. YouTube still receives the network information necessary to deliver the player. The site preserves a strict-origin referrer because YouTube requires site identity for embedded playback. If you do not want that connection, use the original link or do not start the player.

AI studio

The text selector offers gemma-4-26b-a4b-it (@cf/google/gemma-4-26b-a4b-it), hosted through Cloudflare Workers AI. Tutor and document prompts are sent to Pigsfield's same-origin /api/ai endpoint. Visitors do not log in, provide an additional provider key or download a model. Pigsfield and Cloudflare receive the request information needed to process a prompt. Rate limits, shared allocation and service availability apply.

Image prompts use the named Pollinations image service, so those prompts and the network information needed for the request reach Pollinations. Voice preview and music synthesis are offered only when the browser exposes the necessary capability and their output is made in the browser. Generated images, documents and music files remain downloadable where the browser supports the format. External links to Artificial Analysis and Qwen Chat open those providers' own sites and terms. Do not submit personal, confidential, copyrighted or sensitive information to any cloud service. Generated output may be inaccurate, biased or unsuitable and must be reviewed.
